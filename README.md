## Features

| | |
|---|---|
| 💍 **Taaruf** | Jalur taaruf yang sesuai syariat — profil, muhrim, proses serius |
| 📖 **Artikel & Pelatihan** | Materi islami, kursus, dan pelatihan terstruktur |
| 🗣️ **Konsultasi** | Sesi konsultasi dengan narasumber |
| 💬 **Pesan & Grup** | Chat privat dan grup komunitas |

## Install

1. Download the `.apk`
2. Open it — Android will ask permission to install from this source
3. Enable **Allow from this source** when prompted
4. Install, open, register

> Requires **Android 5.0 (API 21)** or newer. ~50 MB download.

## About this repository

This repo holds **APK builds only**. The source code is private.

Builds are triggered by CI on every tagged release. No manual uploads, no tampered binaries — what Actions built is what you download.
